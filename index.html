About This Project

This single-page application was created as a COMP 3512 assignment to demonstrate DOM manipulation, JSON data handling, and client-side state management.

Technologies used: semantic HTML, custom CSS (neutral palette with maroon accents), and vanilla JavaScript with the Fetch API and async/await for loading JSON data.

Fetch API reference: MDN Web Docs – “Using the Fetch API”.

Data set: curated apparel catalog with gender, category, size, color, and sales metadata.

GitHub repository: https://github.com/example/automatic-zoom
